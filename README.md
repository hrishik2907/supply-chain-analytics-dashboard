# 📊 Supply Chain Analytics Dashboard

## Project Overview
Developed an interactive Supply Chain Analytics Dashboard using SQL Server and Power BI to analyze revenue trends, profitability, inventory health, shipping performance, and defect rates.

This dashboard was designed to provide executive-level business insights through KPI reporting, drill-through analysis, custom tooltips, and interactive filtering.

## Tools & Technologies Used
- SQL Server
- Power BI
- DAX
- Data Modeling
- Data Visualization

## Key Features
- Executive Overview Dashboard
- Product Drill-through Analysis
- Interactive Navigation Buttons
- Custom Tooltip Pages
- Conditional Formatting
- KPI Tracking
- Revenue & Profit Trend Analysis
- Inventory & Shipping Insights

## KPIs Tracked
- Total Revenue
- Total Profit
- Average Defect Rate
- Average Shipping Rate
- Inventory Status
- Shipping Performance

## Business Insights
- Skincare products generated the highest estimated profit.
- Healthy stock inventory dominated overall inventory levels.
- Fast shipping products contributed to higher revenue.
- Revenue spikes were observed during Q2 and Q4.
- Moderate defect products represented the largest defect category.

## Project Workflow
1. Imported raw supply chain dataset into SQL Server
2. Cleaned and transformed data using SQL queries
3. Connected SQL Server database to Power BI
4. Built data model and relationships
5. Created DAX measures for KPIs and trend analysis
6. Designed executive overview dashboard
7. Implemented drill-through product analysis
8. Added custom tooltip pages and navigation buttons
9. Applied conditional formatting for performance indicators
10. Generated business insights from dashboard analysis
